Three projects, one platform

Your three repos become one product

I take the idea from each project and rebuild it from scratch with a stronger approach. None of the old code is reused. The git history keeps it if you ever want to look back.

AmerZuher/Super-Image-Quality-Enhancer

AI super-resolution

An RDB network upscales the Y (luminance) channel ×3. FastAPI and Next.js, a compare slider, and a Jupyter notebook for training.

AI Lab with 13 model families and tiled inference, a full Compare viewer, and Forge, which replaces the notebook with a visual model builder.
AmerZuher/Image-modifier

Sort by orientation

Copies photos into "Desktop" and "Mobile" folders by comparing width and height. A terminal menu with tkinter folder pickers.

Library smart albums: rules on orientation, aspect, resolution, color, tags, faces and blur. Albums are views, so no files get copied.
AmerZuher/Image-Modifier-

Duplicates and similar images

Average-hash duplicate finder that keeps the largest file, plus a pHash "find similar" search over a folder.

Library duplicates and search: three hash types plus visual embeddings. It keeps the best copy by sharpness and resolution, and removed files go to quarantine so you can undo.
SIQE StudioStudio · AI Lab · Library · Flows · ForgeWeb app, REST API, CLI and hot folders, all from one Docker Compose stack.
The five workspaces

Everything you can do to an image, in one place

Each workspace has one job. They share the same library, the same job queue and the same models, so an image moves between them without exporting and re-importing.

Studio

A non-destructive editor with live GPU preview.

  • Edit stack you can reorder or turn off
  • Curves, HSL, LUTs, grading
  • Histogram, waveform, vectorscope
  • Copy edits onto 500 photos at once

AI Lab

Run, compare and score AI models.

  • Upscale ×2/×3/×4, restore faces
  • Erase objects, remove backgrounds
  • Colorize, denoise, deblur
  • Compare models side by side

Library

Organize thousands of photos automatically.

  • Duplicates with keep-best rules
  • Find similar, or search by description
  • Smart albums from rules
  • Strip EXIF and GPS data

Flows

Chain operations into a pipeline you can reuse.

  • Visual node editor
  • Batch runs and hot folders
  • Branch on orientation, size, tags
  • Run from the API or CLI

Forge

Design and train your own models without writing code.

  • Drag-and-drop architecture
  • Live shape and parameter checks
  • Dataset builder and live training charts
  • Publish straight to AI Lab

Stronger logic under the hood

      
What changes in the engine

      
Each row is something I found reading your current code, and how the new platform handles it.

    

    

      

        
AreaTodaySIQE Studio

        
          
Model loadingThe Keras model loads from disk on every enhance request.Models load once and stay warm in a GPU worker. The registry swaps them in and out by memory budget.

          
FrameworkTensorFlow 2.10 (2022) with one .h5 model.PyTorch 2 for training, ONNX Runtime for fast inference on CUDA or CPU. Your v10 weights get ported over.

          
Large imagesThe whole image goes through the network in one pass, so big photos run out of memory.Tiled inference with overlap blending. Any size works in fixed memory, with tile-by-tile progress.

          
Long tasksEnhancing runs inside the HTTP request. The browser waits, and a timeout loses the work.A Redis job queue with live progress over WebSocket. Jobs can be cancelled, retried and batched.

          
DuplicatesAverage hash only. Keeps the largest file. Deletes permanently after one y/n prompt.SHA-256 for exact copies, pHash and dHash for edits, CLIP embeddings for near copies. Keeps the best copy, with quarantine and undo.

          
Similar searchHashes and compares every file in the folder on every search.Embeddings are computed once on import and stored in PostgreSQL with pgvector, so each search is an indexed lookup.

          
SortingTwo fixed folders, Desktop and Mobile. Files are copied.Rule-based smart albums on any property. Nothing is copied, and the rules re-run as new photos arrive.

          
TrainingA Jupyter notebook with settings edited by hand.Forge: a visual builder with a shape checker, generated PyTorch, a resumable trainer, live charts and ONNX export.

          
Data and secretsRaw psycopg2 queries. The database password is hard-coded in docker-compose.yml.SQLAlchemy 2 with Alembic migrations. Secrets live in a .env file that stays out of git.

          
Quality checksNo tests or CI.pytest for the engine, Playwright for the UI, and GitHub Actions that build every Docker image on each push.

        
      

    

  







  

    

      
Architecture · fully dockerized

      
Eight containers, one command

      
The default profile runs on any machine with CPU workers. Add --profile gpu and the AI and training workers use your NVIDIA GPU.

    

    

      

        
      

      


# first run
$ cp .env.example .env
$ docker compose up -d                 # CPU, any machine
$ docker compose --profile gpu up -d   # NVIDIA GPU
$ open http://localhost:8080

# models download once into the models/ volume
$ docker compose run --rm api siqe models pull --default

Design language · "Lattice"

      
Built from your logo

      
The SIQE crystal is a cyan lattice with a gold core. The interface follows it: cyan for structure and selection, and gold reserved for AI. When something glows gold, a model is involved.

Gold means AIModel runs, AI nodes and the Enhance button are the only gold elements, so you always know where a model is involved.

      
The image gets the spacePanels collapse around the canvas. Tab hides everything, and \ flips between before and after.

      
Keyboard firstCtrl K opens a command palette for every tool, image, flow and setting. Every tool has a shortcut you can change.

      
Motion with a reasonOne signature moment: when an enhancement finishes, the result sweeps in behind a lattice scan line. Nothing else moves for decoration, and reduced-motion is respected.

      
Dark and lightDark-first like the logo, with a full light theme. Text meets WCAG AA contrast in both, and focus rings are always visible.

      
Works on a phoneLibrary, Flows status and AI Lab work at phone width for uploading and checking results. Studio and Forge are built for desktop.
